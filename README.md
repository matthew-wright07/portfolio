# My Personal Portfolio Project

This Flask app serves HTML, CSS, and JS for my portfolio website

[Portfolio](https://matthewwright.site)

## Overview

I built this project to highlight personal experiences and projects that are relevant to me over the years

## Tech Stack

This app runs using Flask and all other dependencies can be found in [requirements.txt](./requirements.txt)

Python

Pip or other package manager
